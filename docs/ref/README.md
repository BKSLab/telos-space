# Референсы и исторические снимки

## Дашборды проекта и портфеля

[Визуальная спецификация](TELOS_SPACE_DASHBOARD_VISUAL_SPEC.md) и
[генеративный макет](dashboard-reference.png) — материалы следующей доработки
обзоров. Они не описывают уже реализованный интерфейс.

Согласовано сохранить текущую тёмную тему TELOS SPACE: сине-чёрный фон картинки
не переносится. Логотипы проектов должны быть заметнее в карточках и участвовать
в оформлении шапки проекта. Отсутствие пользовательского логотипа обрабатывается
существующей дефолтной иконкой; дальнейшее изменение её дизайна не согласовано.
Значения, вкладки и названия на картинке иллюстративны. Реализация опирается
на настоящие данные и [дизайн-гайд](../DESIGN_GUIDE.md).
